# advisor-workbench

Unified UI for advisor workflows, currently scoped to DPM proposal simulation.

## Standard Frontend Stack

- Next.js (App Router)
- React + TypeScript
- TanStack Query
- MUI
- AG Grid
- ECharts
- React Hook Form
- Zod

## Quickstart

```bash
npm install
npm run dev
```

Open `http://localhost:3000/proposals/simulate`.

Set `BFF_BASE_URL` to point to `advisor-experience-api`.
